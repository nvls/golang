Primeros pasos en Golang 👣

Proyecto Básico en Golang.
-
Este proyecto contiene lo siguiente:

- Struct Tarea (ID, Descripción, fecha de creación y fecha de modificación)
- Conexión a una Base de Datos en Postgresql
- Acrhivo Repositorie para listar todas las tares, crear una tarea y consultar una tarea por ID.
- Archivo Service
- Archivo Handler
- Se está utilizando Gin como enrutador para el manejo de la operaciones GET, y PUT
